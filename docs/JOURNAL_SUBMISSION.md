# DMKD submission and archival record

Data Mining and Knowledge Discovery requires a Data Availability Statement in original research. Identify the data supporting the results, give repository links or citations for public material, and explain how to obtain restricted material and what conditions apply. Publish only material the authors are entitled to redistribute. [DMKD submission guidelines](https://link.springer.com/journal/10618/submission-guidelines#research-data-policy-and-data-availability-statements)

Springer Nature requires a Code Availability Statement for original research with newly developed code needed to interpret or replicate its conclusions. Identify the code, its location, and its access terms. Publish a numbered GitHub release for access and version tracking, and archive that exact version in a service that assigns a permanent identifier, such as Zenodo. Cite the version DOI in the paper's references. Using an OSI-approved license is encouraged. [Springer Nature code policy](https://www.springernature.com/gp/open-science/code-policy) · [GitHub guide to DOI archiving](https://docs.github.com/en/repositories/archiving-a-github-repository/referencing-and-citing-content)

## Manuscript wording for the corresponding author

Use the following statements once the public release and archive are verified. Replace each placeholder with the final URL or DOI. Cite a separate data DOI if the supporting records are deposited separately.

**Code availability.** The author-developed DVKG code for constructing shared concept graphs and textbook structure graphs, aligning the two views, and running the accompanying evaluation is available in the [versioned GitHub release]. An archival copy of this version is available at [version DOI]. The release includes installation and usage instructions.

**Data availability.** The [archived evaluation records or release URL] provide the released score tables, per-question numeric F1 scores, and paragraph identifiers for replaying reported Recall@5 for the released records. The F1 records support aggregation of stored scores. The textbook files, extracted passages, and restricted evaluation text are subject to the applicable access terms and are excluded from the public archive. The release documents the textbook editions and the inputs needed to rerun the workflows with copies obtained through the corresponding publishers or other lawful sources.
